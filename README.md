# Solid — SolidWorks API лабораторные

Автоматизация построения детали в SolidWorks через COM API (Interop). Каждая
лабораторная — отдельное решение на **.NET Framework 4.8 + WinForms**.

## Структура репозитория

```
Lab4/                      Лаб. №4 — построение 2D-эскиза детали
├── Lab4.sln
├── Lab4.App/              WinForms-приложение (UI с параметрами и кнопками)
└── SolidWorksApi/         Изолированная обёртка над COM-объектами SolidWorks
                           (SldWorks, ModelDoc2, SketchManager) и хелперы для
                           построения линий, дуг, окружностей, образмеривания

Lab5/                      Лаб. №5 — построение 3D-модели детали
├── Lab5.sln
├── Lab5.App/              WinForms с TabControl: «Главная» + 4 шага построения
└── SolidWorksApi/         Та же обёртка + FeatureManager (FeatureExtrusion3,
                           FeatureCut4) и работа с гранями возвращаемых Feature
```

## Требования

* Windows + установленный SolidWorks (рекомендуется 2022+, тестировалось на
  SolidWorks 2024).
* .NET Framework 4.8 Developer Pack.
* Visual Studio 2022 (Community достаточно).

## Сборка

1. Открыть нужное решение (`Lab4/Lab4.sln` или `Lab5/Lab5.sln`) в Visual
   Studio.
2. Visual Studio автоматически восстановит ссылки на интероп-сборки SolidWorks
   (`SolidWorks.Interop.sldworks.dll`, `SolidWorks.Interop.swconst.dll`).
   Если что-то не найдено — указать путь к каталогу `<SolidWorks>\api\redist`
   в `Project → Properties → Reference Paths`.
3. Запустить `Lab4.App` или `Lab5.App` (F5).

## Запуск лабораторных

### Лаб. №4 — 2D-чертёж

Кнопка **«Подключиться к SolidWorks»** запускает экземпляр SolidWorks
(или подключается к запущенному) и создаёт новый эскиз на плоскости
*Спереди*. Кнопка **«Построить»** строит контур детали по параметрам из
текстовых полей; **«Очистить»** удаляет построенные элементы;
**«Сохранить как…»** вызывает `SaveFileDialog` и сохраняет файл `.SLDPRT`.

### Лаб. №5 — 3D-модель

Окно содержит вкладки:

* **Главная** — подключение к SolidWorks, открытие новой детали, сохранение.
* **Шаг 1** — основание (выдавливание прямоугольника симметрично от средней
  плоскости).
* **Шаг 2** — верхняя «надстройка» с трапециевидной верхней гранью
  (выдавливание + наклонный срез).
* **Шаг 3** — вертикальный паз `25 × 35` сбоку (`FeatureCut4`).
* **Шаг 4** — полукруглый вырез `R30` посередине передней грани (`FeatureCut4`).

Каждый шаг выполняется автономно (доступ к API изолирован в проекте
`SolidWorksApi`).

## Замечания

* Все параметры построения вынесены в текстовые поля; перевод **мм → м**
  делается централизованно в обёртке (`Mm.ToMeters`).
* Логика API вынесена в отдельный проект `SolidWorksApi` — `*.App` зависит
  от него, но не работает с COM напрямую (соответствует требованию лабы).
* Для надёжного освобождения COM-объектов используется
  `Marshal.ReleaseComObject` и блок `using` для эскиза.
